# اعتبارسنجی نسخه ۰٫۷

تاریخ: ۲۰۲۶/۱۰/۱۶ به وقت تهران. محیط اجرا Linux، Python 3.12.14 و Chromium واقعی است. هر دو نصاب مستقل و سرور شبکه از همین سورس ساخته شدند؛ نسخه نصب هر دو `0.7.0` است.

## رفتار بررسی‌شده

- جستجوی سراسری سربرگ حذف شده و فهرست‌های مرجع با تایپ متن، کلیدهای جهت و Enter قابل انتخاب‌اند. جستجوی فارسی/عربی، شناسه واقعی گزینه، خطای انتخاب نامعتبر، فهرست پویا، فرم الزامی و پنجره modal بررسی شدند.
- تقویم تجمیعی و برنامه‌ریزی افراد بین شرکت‌ها فقط برای ادمین هلدینگ است. مدیر شرکت فقط دوره داخلی خودش را می‌سازد و تغییر می‌دهد. دسترسی به تقویم تجمیعی و تغییر دوره هلدینگ در API نیز برای کاربران شرکت رد می‌شود. ارجاع به دوره‌های قبلی در سوابق همان شرکت باقی می‌ماند.
- افزودن، ویرایش و حذف بانک شایستگی همچنان مخصوص ادمین است؛ شرکت‌ها انتخاب و استفاده می‌کنند. حذف مورد دارای وابستگی سوابق را از بین نمی‌برد.
- ذخیره هم‌زمان، تغییر شرکت هنگام نوشتن، پاسخ قدیمی شرکت دیگر، خروج نشست، خطای موقت دریافت و تلاش مجدد، حفظ فرم و تغییرات چندسطحی پس از خطا، و حفظ پیش‌نویس بارگذاری گواهینامه هنگام حذف مدرک قبلی آزمایش شدند.
- JSON خراب، شناسه خارج از محدوده، مقدار عددی یا ارتباط نامعتبر و تاریخ شمسی نامعتبر با خطای کنترل‌شده رد می‌شوند. درخواست نامعتبر نباید ذخیره ناقص ایجاد کند. تاریخ کبیسه ۱۴۰۳/۱۲/۳۰ پذیرفته و ۱۴۰۴/۱۲/۳۰ رد می‌شود.

## بسته‌ها و ارتقا

Python رسمی 3.13.16 ویندوز با SHA512 مرجع، و RECORD وابستگی‌های wheel پیش از ساخت بررسی شدند. نصاب‌ها EXE واقعی NSIS هستند. پس از استخراج، SHA256 تمام ۱۷۸۰ فایل manifest مستقل و ۲۰۱۹ فایل manifest شبکه تأیید شد. همه فایل‌های سورس بسته‌شده با سورس نهایی برابرند و ماژول اعتبارسنجی و فایل‌های انتخابگر قابل جستجو داخل هر دو نصاب وجود دارند. پایگاه محلی، کلید خصوصی یا داده بهره‌برداری داخل بسته‌ها نیست.

[اندازه، SHA256 و شواهد بررسی فایل‌ها](build-verification-0.7.json)؛ فایل‌های checksum و manifest در پوشه `distribution` نیز منتشر می‌شوند. نصاب میانبر کلاینت همان نسخه محصول `0.5.0` است؛ ارتقای سرور منطق سامانه را به‌روز می‌کند.

اعتبارسنج مستقل روی کد استخراج‌شده با محیطی که فقط وابستگی‌های مستقل را دارد اجرا شد؛ کنترل نقش، تقویم‌ها، بانک، افراد بین شرکت‌ها، پشتیبان SQLite و چرخه واقعی شروع/توقف `desktop.py` موفق بود. سناریوهای مرورگر تقویم، بانک، انتخابگر و شناسنامه نیز روی همین برنامه استخراج‌شده بررسی شدند.

اعتبارسنج شبکه روی کد استخراج‌شده با سرور HTTPS واقعی و تأیید گواهی اجرا شد؛ ۱۶ ثبت هم‌زمان، جداسازی شرکت‌ها، محدودیت برنامه‌ریزی، پشتیبان رمزگذاری‌شده و بازیابی فهرست افراد، رمزها، پیوست و شناسنامه موفق بود. حفاظت در برابر جایگزینی پایگاه سرور فعال نیز بررسی شد.

برای ارتقای ۰٫۶ به ۰٫۷، داده آزمایشی با نسخه استخراج‌شده ۰٫۶ ساخته و با نسخه استخراج‌شده ۰٫۷ باز شد. [گزارش حفظ داده](upgrade-0.6-to-0.7.json) برابری ردیف‌ها، شناسه‌ها و محتوای موجود را قبل از عملیات جدید بررسی می‌کند. تغییر schema جدیدی برای این نسخه لازم نیست؛ داده و نوع تقویم موجود بازنویسی نمی‌شود.

## محدوده تأیید

اجرای کد استخراج‌شده با Python روی Linux، اجرای runtime ویندوز یا خود نصاب روی Windows نیست. نصب واقعی ۰٫۷، Scheduled Task، shortcut، ارتقا و حذف نصب روی Windows در این محیط اجرا نشده‌اند. workflow ویندوز برای شاخه جاری و برچسب‌های انتشار به‌روز شده و گزارش‌ها را به‌صورت artifact نگه می‌دارد؛ پیکربندی آن به‌تنهایی تأیید موفقیت اجرا نیست. گزارش‌های Windows نسخه‌های قبلی نیز تأیید این ساخت جدید محسوب نمی‌شوند.
