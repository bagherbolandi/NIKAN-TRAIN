# وضعیت تحویل ۰٫۱۳ — ۱۴۰۵/۰۸/۲۳

مدیریت شرکت‌ها و سایت‌ها برای ادمین اصلی تکمیل شد. نفرات مستقر، فعالیت موقت و افراد بدون سایت جدا نمایش داده می‌شوند؛ شرکت انتخاب‌شده در سربرگ و فضای کاری هماهنگ است. حذف ساختار دارای سابقه یا مجوز رد می‌شود و شناسه‌های حذف‌شده تکرار نمی‌شوند.

آکورد بهره‌وری از امتیازهای موجود عملکرد استفاده می‌کند، با هشت شاخص پیشنهادی قابل ویرایش، روش مبلغ مبنای فرد یا بودجه مشترک، مشارکت تأییدشده، حداقل امتیاز اختیاری، مبلغ دقیق ریالی، پیش‌نمایش، تأیید و مستند ثابت محاسبه و Excel. دسترسی مالی مستقل است؛ نمره ناقص یا پیش‌نمایش منقضی نهایی نمی‌شود. تغییر نمره یا انتقال بعدی، نتیجه قطعی قبلی را بازنویسی نمی‌کند.

**۴۵۹ آزمون موفق، یک آزمون مخصوص Windows اجرا‌نشده، بدون شکست**. مرورگر واقعی گردش جدید و گردش قبلی HRM را تأیید کرد. مهاجرت واقعی از سه نسخه ۰٫۱۰، ۰٫۱۱٫۲ و ۰٫۱۲٫۱ با حفظ اطلاعات قبلی بررسی شد. بسته‌های نصب آزمایشی، سرور و کلاینت ساخته شده‌اند؛ بررسی محتوای استخراج‌شده در گزارش جاری ثبت می‌شود. نتیجه اجرای نصب بومی Windows هنوز مشاهده نشده است.

اطلاعات کارکنان را مسئولان مجاز وارد می‌کنند؛ حساب یا کارتابل کارکنان وجود ندارد. ادمین اصلی دسترسی کامل دارد و مدیران دیگر فقط بخش‌ها، سایت‌ها و عملیات واگذارشده را انجام می‌دهند.
