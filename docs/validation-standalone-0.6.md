## نصب و محدودیت بررسی

پیش از ارتقا از داخل برنامه پشتیبان بگیرید و با «بستن برنامه» آن را کاملاً ببندید. نصاب جدید را با همان حساب Windows اجرا کنید. داده در `%LOCALAPPDATA%\NikanTraining` و برنامه در `%LOCALAPPDATA%\Programs\NikanTraining` باقی می‌ماند؛ حذف نصب، پوشه داده را پاک نمی‌کند.

اجرای خود فایل EXE، میانبرها و ارتقای نصب روی Windows در این محیط انجام نشده است. آزمون‌های زنده بالا با مفسر Linux و سورس استخراج‌شده از بسته اجرا شدند؛ runtime ویندوز داخل بسته اجرا نشده است. گزارش‌های قدیمی Windows مخزن، تأیید این ساخت جدید محسوب نمی‌شوند.

نسخه مستقل اطلاعات همه شرکت‌های ثبت‌شده در پایگاه همان رایانه را تجمیع می‌کند. نصب‌های جداگانه خودکار همگام نمی‌شوند. انتشار فایل جدید در GitHub در این مرحله انجام نشده است.
