## نصب Windows Server در شبکه داخلی

۱. نصاب Server را با دسترسی Administrator اجرا کنید. مسیر پیش‌فرض: `C:\Program Files\NikanTrainingServer`.
۲. از منوی Start، **Initialize Nikan Server** را با دسترسی Administrator اجرا کنید. اگر میانبر به صورت عادی باز شد، روی آن راست‌کلیک و Run as administrator را انتخاب کنید. حساب مدیر را در مرورگر محلی بسازید؛ سپس پنجره اجرای اولیه را با Ctrl+C ببندید. این مرحله فقط روی loopback اجرا می‌شود.
۳. PowerShell را با Run as administrator باز کنید و اجرا کنید:

```powershell
& 'C:\Program Files\NikanTrainingServer\install-server.ps1'
```

اگر سیاست اجرای سازمان مانع اسکریپت است، واحد IT باید اسکریپت را بررسی و مطابق سیاست خود امضا یا برای همان اجرا مجاز کند؛ سیاست سراسری سیستم را تغییر ندهید.

۴. از مرورگر رایانه کاربر به `http://SERVER-NAME:8766` متصل شوید. فایروال فقط برای شبکه Domain/Private و LocalSubnet باز می‌شود. دسترسی شبکه‌های دیگر شرکت‌ها یا VPN را واحد IT متناسب با subnet واقعی تنظیم کند.
۵. Task Scheduler شامل `NikanTrainingServer` برای اجرا هنگام روشن‌شدن و `NikanTrainingBackup` برای پشتیبان روزانه ساعت ۰۲:۰۰ به وقت خود سرور خواهد بود. هر دو با حساب محدود Local Service اجرا می‌شوند. خاموش‌شدن نشست مدیر باعث توقف سرور نمی‌شود.
۶. داده و تنظیمات: `%PROGRAMDATA%\NikanTrainingServer`. فایل `server.json` شامل `host`، `port` و `https` است. هنگام تغییر پورت، قانون فایروال را نیز اصلاح کنید. برای اعمال تنظیمات Task سرور را Stop/Start کنید.

برای استقرار عملیاتی دارای اطلاعات کارکنان، HTTPS را با گواهی معتبر سازمان و reverse proxy واحد IT تنظیم کنید. در این حالت backend را روی `127.0.0.1` قرار دهید، Host اصلی را در proxy حفظ کنید و هدر X-Forwarded-Proto را در همان proxy به https تنظیم کنید، دسترسی مستقیم پورت backend را ببندید و `https` را true کنید. گواهی و DNS اختصاصی سازمان در این بسته ساخته نشده‌اند. برای شبکه‌های پرترافیک ابتدا تست بار با تعداد کاربران واقعی انجام شود؛ دیتابیس SQLite روی دیسک محلی سرور است و نباید روی پوشه اشتراکی SMB قرار گیرد.

برای نیاز مصوب، هدف قابل سنجش، روش توسعه، مسئول، مهلت شمسی، معیار موفقیت، مبنا و هدف را وارد کنید. انتخاب دوره مرتبط از تقویم اختیاری است؛ مربیگری یا اقدام غیرآموزشی نیز قابل ثبت است. ثبت نتیجه واقعی به شاهد و تاریخ ارزیابی نیاز دارد. واحد و جهت موفقیت (بیشتر/کمتر) را در معیار بنویسید؛ سامانه از مقایسه خام دو عدد، حکم خودکار موفقیت صادر نمی‌کند. ارزیابی شایستگی فرد پس از اقدام باید جداگانه ثبت شود.

## دیتابیس، ارتقا و بازیابی

فایل نمونه `database\nikan-empty.sqlite3` شامل ساختار و بانک مرجع است، نه حساب آماده یا اطلاعات کارکنان. اجرای عادی سامانه خودش دیتابیس را می‌سازد؛ فایل نمونه را روی دیتابیس واقعی کپی نکنید. جداول جدید `need_reviews`، `development_plans` و `schema_migrations` افزایشی هستند.

پیش از ارتقا، برنامه را متوقف و پشتیبان معتبر تهیه کنید. برای انتقال از نصب مستقل به سرور، فقط یک دیتابیس مرجع انتخاب کنید؛ ادغام خودکار دیتابیس چند نصب مستقل وجود ندارد. فایل پشتیبان مستقل را پس از توقف سرور به عنوان `nikan.sqlite3` در پوشه داده سرور قرار دهید. فایل‌های قدیمی WAL و SHM نباید با دیتابیس جایگزین مخلوط شوند؛ کل پوشه داده قبلی را با نام دیگری نگه دارید و بازیابی را در پوشه تازه انجام دهید. بعد از راه‌اندازی مجدد، کاربران و تعداد رکوردها را بررسی کنید.

پشتیبان سرور با SQLite Backup API گرفته می‌شود و تصویر سازگار دیتابیس شامل پیوست‌های ذخیره‌شده در دیتابیس است. فایل‌ها در `backups` باقی می‌مانند؛ حذف خودکار ندارند. انتقال دوره‌ای به محل جدا و سیاست نگهداری بر عهده IT است. پشتیبان‌های این نسخه رمزگذاری‌شده نیستند؛ سطح دسترسی پوشه محدود شده و برای ذخیره خارج سرور از فضای امن/رمزگذاری سازمان استفاده کنید.

پشتیبان دستی:

```powershell
& 'C:\Program Files\NikanTrainingServer\runtime\python.exe' 'C:\Program Files\NikanTrainingServer\server.py' --backup
```

پیش از جایگزینی فایل‌های اجرایی سرور، Task سرور را متوقف کنید. حذف نصب، داده‌های ProgramData/LocalAppData و پشتیبان‌ها را پاک نمی‌کند. اسکریپت `unregister-server.ps1` وظایف زمان‌بندی و قانون فایروال این سامانه را حذف می‌کند.

## مبنای آموزشی و حدود اعتبارسنجی

اعتبارسنجی محلی شامل آزمون API، نقش‌ها، تعارض تصمیم، ارتقای تکرارپذیر، سلامت دیتابیس و گردش مرورگر فارسی است. اجرای واقعی Task Scheduler با حساب Local Service، قواعد شبکه سازمان و نصب روی خود Windows Server مقصد باید هنگام تحویل IT بررسی شوند. نصاب‌ها امضای دیجیتال تجاری ندارند.

## بازیابی رمز ورود
در صفحه ورود «رمز عبور را فراموش کرده‌ام» را انتخاب کنید. برای نصب مستقل، میانبر **Nikan Password Recovery** در منوی Start، زیر Nikan Training، کد بازیابی تولید می‌کند. نام کاربری را در پنجره آن وارد کنید. در نسخه سرور، مدیر مجاز Windows Server همین میانبر را با Run as administrator اجرا می‌کند. کاربران شرکت‌ها کد را از مدیر دریافت می‌کنند؛ تولید کد از مرورگر در دسترس نیست.
کد یک‌بارمصرف است و ۳۰ دقیقه اعتبار دارد؛ ۵ تلاش نادرست کد را غیرفعال می‌کند و باید کد تازه بگیرید. کد جدید، کد قبلی همان حساب را باطل می‌کند. در فرم بازیابی، نام کاربری، کد، رمز جدید و تکرار آن را وارد کنید. رمز حداقل ۱۲ و حداکثر ۲۵۶ نویسه است. با بازیابی موفق، رمز قبلی و تمام نشست‌های قبلی حساب باطل می‌شوند. اطلاعات شرکت‌ها و کارکنان تغییر نمی‌کنند. هیچ کد عمومی یا رمز ثابت برای همه نصب‌ها وجود ندارد.
برای اجرای دستی روی رایانه محلی: `runtime\python.exe recover_account.py`. روی سرور: `runtime\python.exe recover_account.py --server`. اختیار دسترسی به فایل دیتابیس همان اختیار بازیابی محلی است؛ پوشه داده سرور باید به حساب سرویس و مدیران ویندوز محدود بماند.
