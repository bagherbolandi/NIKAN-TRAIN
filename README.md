# سامانه مدیریت آموزش هلدینگ نیکان

نسخه اجرایی اولیه برای **نصب مستقل روی رایانه ویندوز**، با رابط فارسی و راست‌به‌چپ. سرور داخلی فقط روی `127.0.0.1` اجرا می‌شود و رابط در مرورگر محلی باز می‌شود. داده‌های رایانه‌های مختلف همگام نمی‌شوند. این معماری برای استفاده مستقل طراحی شده؛ برای مدیریت زنده و مشترک شرکت‌ها از چند رایانه، نسخه مرکزی و پایگاه داده سرور لازم است.

## نصب و اجرا روی ویندوز

1. Python نسخه 3.12 یا جدیدتر را از python.org نصب کنید؛ گزینه Python Launcher را فعال بگذارید.
2. بسته را در پوشه‌ای با دسترسی نوشتن استخراج کنید.
3. `Install-Windows.cmd` را اجرا کنید. نصب اولیه به اینترنت برای دریافت بسته‌ها از PyPI نیاز دارد.
4. `Start-Nikan.cmd` را اجرا کنید. مرورگر صفحه ورود را باز می‌کند. پنجره اجرا باید باز بماند.
5. در اولین اجرا، نام کاربری مدیر و رمز عبور حداقل ۱۲ نویسه‌ای تعیین کنید. حساب یا رمز پیش‌فرض وجود ندارد.
6. شرکت را در بالای صفحه انتخاب کنید. از مدیریت کاربران برای هر شرکت حساب مسئول آموزش یا مشاهده‌گر بسازید.

این تحویل شامل اسکریپت نصب و کد قابل اجرا است، **نصاب مستقل EXE/MSI بدون Python نیست**. اجرای واقعی روی ویندوز در محیط فعلی آزمایش نشده است.

## شرکت‌ها و دسترسی‌ها

- نور ایستا پلاستیک
- نور ایستا خراسان
- برنا کامپوزیت ایرانیان
- پایا پلاست ایرانیان
- پلیمری تدبیر نیکان
- ایمن ایستا الکتریک

مدیر هلدینگ همه شرکت‌ها را می‌بیند؛ مسئول آموزش فقط اطلاعات شرکت خود را ثبت و ویرایش می‌کند؛ مشاهده‌گر فقط اطلاعات شرکت خود را می‌بیند. شناسه شرکت و مالکیت رکوردهای مرتبط در بک‌اند کنترل می‌شوند. جابه‌جایی انتخاب شرکت، داده‌ها را به شرکت دیگری منتقل نمی‌کند.

## گردش کار

1. **ورود اکسل:** فایل اصلی را از منوی ورود اطلاعات انتخاب کنید. کاتالوگ مهارت و الزامات شغلی به شرکت انتخاب‌شده منتقل می‌شوند. فقط زمانی گزینه پرسنل را فعال کنید که انتساب افراد به آن شرکت را تأیید کرده‌اید. فایل اکسل نام شرکت واقعی را مشخص نکرده است؛ بنابراین انتساب خودکار انجام نمی‌شود.
2. **پرسنل:** کد پرسنلی، نام، واحد و سمت را ثبت یا ویرایش کنید. عنوان سمت باید با شناسنامه شغلی مطابقت داشته باشد.
3. **شناسنامه شغلی:** سطح لازم هر مهارت برای هر سمت را تعیین کنید؛ I=1، L=2، U=3، O=4.
4. **ماتریس شایستگی:** سطح فعلی افراد را ثبت کنید. سطح صفر یعنی فاقد سطح ثبت‌شده.
5. **نیازسنجی:** سامانه فاصله سطح لازم از سطح مؤثر را محاسبه می‌کند. سطح مؤثر، بیشینه ارزیابی و سطح حاصل از دوره‌های برگزارشده همان مهارت است. خروجی CSV برای Excel قابل دریافت است.
6. **برنامه و تقویم:** دوره، مهارت، تاریخ شمسی، مدرس، ساعت، هزینه و وضعیت برنامه‌ریزی/مصوب/برگزارشده/لغوشده را ثبت کنید. نمای ماهانه دوره‌ها بالای جدول دیده می‌شود.
7. **سوابق و اثربخشی:** برای هر فرد و دوره سطح حاصل، نمره آزمون، رضایت، نظر مدیر و تحقق شاخص هدف را ثبت کنید. فقط دوره با وضعیت برگزارشده در کاهش گپ اثر دارد.
8. **داشبورد و رویدادها:** تعداد پرسنل، مهارت‌ها، گپ‌ها، دوره‌ها، بودجه و عملیات ثبت‌شده را ببینید.

ورود اکسل تکرارپذیر است: رکوردهای موجود را بازنویسی نمی‌کند. کاتالوگ، الزامات شغلی، پرسنل و ماتریس مهارت منتقل می‌شوند. سوابق آموزشی، تصمیم‌های کمیته، مدرسان و سایر برگه‌ها هنوز مبدل خودکار ندارند؛ داده‌های آنها از فرم‌های سامانه ثبت می‌شوند. فرمول‌های اکسل اجرا یا بازنویسی نمی‌شوند. فایل اصلی تغییر نکرده است.

## پایگاه داده و حفاظت

داده‌ها پیش‌فرض در `%LOCALAPPDATA%\NikanTraining` قرار دارند؛ فایل `nikan.sqlite3` پایگاه داده است و `session.key` کلید امضای نشست. متغیر اختیاری `NIKAN_DATA_DIR` مسیر را تغییر می‌دهد.

SQLite با کلیدهای خارجی، تراکنش‌ها، WAL و timeout فعال است. رمزهای کاربران با scrypt هش می‌شوند؛ کوئری‌ها پارامتری‌اند؛ درخواست‌های تغییر داده CSRF دارند؛ نشست HttpOnly و SameSite است؛ پس از پنج ورود ناموفق، آن نام کاربری ۱۵ دقیقه محدود می‌شود. داده‌ها روی دیسک به‌طور پیش‌فرض رمزگذاری نشده‌اند: برای رایانه سازمانی از BitLocker و حساب ویندوز با دسترسی محدود استفاده کنید. این نرم‌افزار ممیزی مستقل امنیتی نشده است.

نسخه محلی را با تغییر دستی host در شبکه منتشر نکنید. استقرار شبکه‌ای نیازمند HTTPS، سیاست نشست و پشتیبان‌گیری مرکزی و بازنگری معماری است.

## پشتیبان‌گیری و بازیابی

مدیر از منوی پشتیبان‌گیری یک snapshot سازگار SQLite دریافت می‌کند. فایل شامل داده‌های هر شش شرکت و هش رمز کاربران است؛ آن را در محل امن نگهداری کنید.

برای بازیابی: برنامه را کاملاً ببندید؛ از پوشه داده فعلی یک کپی امن بگیرید؛ فایل پشتیبان را با نام `nikan.sqlite3` جایگزین کنید و فایل‌های قدیمی `nikan.sqlite3-wal` و `nikan.sqlite3-shm` را تنها پس از توقف کامل برنامه کنار بگذارید. سپس برنامه را اجرا کنید. پوشه کلید نشست را امن نگه دارید؛ پاک شدن کلید باعث خروج نشست‌ها می‌شود، نه پاک شدن داده‌ها. بازیابی را ابتدا روی یک مسیر داده جداگانه با `NIKAN_DATA_DIR` آزمایش کنید.

## توسعه و آزمون

```bash
python -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m pip install pytest==8.4.2
.venv/bin/python -m pytest -q
.venv/bin/python run.py --no-browser
```

در ویندوز مسیر Python محیط مجازی `.venv\Scripts\python.exe` است. بک‌اند Flask و Waitress، فرانت‌اند HTML/CSS/JavaScript بدون CDN یا سرویس بیرونی، پایگاه داده SQLite و مبدل Excel مبتنی بر openpyxl هستند.

## دامنه نسخه فعلی

این نسخه پایه قابل اجراست، نه تأییدیه آماده‌بودن برای بهره‌برداری نهایی هلدینگ. آزمون‌های API شامل تفکیک شرکت‌ها، CSRF، نقش مشاهده‌گر، محدودسازی ورود، چرخه آموزش و کاهش گپ، ورود تکرارپذیر اکسل و دریافت پشتیبان هستند. گردش کار تأیید چندمرحله‌ای، پیوست مدارک و گواهینامه، حضور و غیاب جلسه‌ای، کاتالوگ مستقل مدرسان، امضای دیجیتال، بازیابی داخل رابط، همگام‌سازی نصب‌ها، نصاب EXE/MSI و آزمون کاربری واقعی ویندوز در این نسخه تکمیل نشده‌اند.

آزمون اختیاری مرورگر واقعی: پس از نصب `requirements-dev.txt` و Chromium، دستور `python tests/browser_smoke.py` را اجرا کنید. آزمون یک سرور و پایگاه داده موقت می‌سازد و در پایان سرور را متوقف می‌کند. در محیط لینوکس فعلی از `/usr/bin/chromium` استفاده می‌کند؛ مسیر مرورگر برای محیط دیگر باید تنظیم شود. تصویر آزمون پیش‌فرض در `/tmp/nikan-dashboard.png` ذخیره می‌شود.
