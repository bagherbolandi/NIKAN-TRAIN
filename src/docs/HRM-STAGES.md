- ⚠️ نسخه‌های مستقل همگام‌سازی خودکار ندارند؛ برای داده مرکزی فقط نصاب Server را مستقر کنید.

## مسیر ارتقا به SQL Server Express (در صورت نیاز واقعی)
هم‌اکنون SQLite کافی است (یک سرور، دیسک محلی، WAL، پشتیبان سازگار). اگر تعداد نویسنده‌های هم‌زمان یا سیاست سازمان مستلزم DBMS سرویس‌دار شد:
1. `SQL Server Express` (رایگان، محلی، بدون اینترنت) نصب و دیتابیس `NikanHRM` بسازید.
2. تمام SQL این ماژول‌ها ANSI و بدون توابع اختصاصی SQLite است به‌جز `json_valid`/`json_type` در `requests.payload` و `employees.passport_aliases` (لایه قدیمی)؛ این دو CHECK را با `IsJson()` یا اعتبارسنجی سمت سرور جایگزین کنید.
3. لایه دسترسی `app.hrm.core.Hrm.c` را به یک آداپتور `pyodbc` پشت همان `db()` متصل کنید؛ `PRAGMA`ها و `BEGIN IMMEDIATE` را به `BEGIN TRAN`/`WITH (UPDLOCK, HOLDLOCK)` نگاشت کنید.
4. Migrationها را دوباره روی دیتابیس تازه اجرا و `test_hrm.py` را بدون تغییر انتظار اجرا کنید.
این کار عمداً در این مرحله انجام نشد تا «سرویس غیرضروری» به پروژه اضافه نشود.
